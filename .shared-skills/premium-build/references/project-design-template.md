# Project Design Files

ProjectOS v1.1.0 may create three project-specific design files for Premium Build repositories.

## `docs/DESIGN_SYSTEM.md`

Record the product's actual visual and interaction decisions: typography, density, spacing, color, surfaces, navigation, control hierarchy, data presentation, motion, responsive behavior, and reusable patterns. Keep this product-specific.

## `docs/UX_FLOWS.md`

Record important user journeys, decision points, failure/recovery paths, and state transitions. Prefer concrete workflows over generic UX principles.

## `docs/VISUAL_REFERENCES.md`

Record references that materially inform the product, what is useful about each reference, and what should not be copied. A reference is inspiration or evidence, not permission to clone another product.
