# Quality Budgets

Set targets based on the product. Do not invent arbitrary numbers.

## Performance
Startup, interaction latency, bundle size, memory, network, or throughput targets where relevant.

## Reliability
Retry behavior, availability expectations, data-loss tolerance, recovery expectations.

## Accessibility
Keyboard, semantic structure, contrast, focus, reduced motion, zoom/text resizing.

## Security
Authentication, authorization, secret handling, dependency expectations, least privilege.

## AI systems
Evaluation thresholds, tool permissions, fallback behavior, hallucination tolerance, cost limits, and human approval requirements when relevant.

## Engineering
Dependency constraints, complexity limits, test expectations, supported environments.
