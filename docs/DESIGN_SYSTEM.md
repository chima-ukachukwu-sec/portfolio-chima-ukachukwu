# Design System

## Product character

Describe the intended visual character, audience, trust level, and workflow density.

## Typography

Document type roles, sizes or tokens, numeric behavior, and any font decisions.

## Layout and spacing

Document containers, grid/alignment rules, spacing relationships, and density.

## Color and surfaces

Document semantic colors, accent usage, surfaces, borders, and elevation.

## Navigation and interaction

Document navigation patterns, primary/secondary actions, keyboard behavior, and interaction conventions.

## Motion

Document where motion is useful, where it is intentionally absent, and reduced-motion behavior.

## Responsive behavior

Document how major layouts and critical actions adapt across supported viewport classes.

## Reusable patterns

Record product-specific primitives and patterns agents should preserve.
