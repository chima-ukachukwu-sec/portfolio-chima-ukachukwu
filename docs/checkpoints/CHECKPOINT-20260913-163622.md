## Architecture decisions

1. **The builder was improved in place, not replaced.** Single source, variant tables,
   `FACT_GUARD`, phone / nophone behaviour, layout and styling all preserved.
2. **A new local repository rather than versioning `~/Documents/resume-private` directly.**
   That directory holds recruiter correspondence and LinkedIn strategy notes that must not enter
   version control. Copying the builder out was cheaper and safer than curating exclusions.
3. **Word remains the PDF step.** It produced every existing PDF and carries the docx core
   properties into the output. A headless converter would have changed both layout and metadata
   silently. Word 16.78 needs `active document` rather than the result of `open`, and a raised
   AppleEvent timeout on first launch.
4. **Keywords do not vary by variant.** A variant reorders emphasis and never makes a different
   claim, so varying the keywords would break the same rule `FACT_GUARD` exists to enforce.

## Security decisions

- The resume repository has no remote and must not gain one. It carries a full career record
  and direct contact details. Verified empty after every commit.
- Recruiter correspondence and strategy notes were excluded by explicit enumeration, then the
  staged file list was scanned for them before the baseline commit.
- `.claude/CANONICAL_FACTS.md` was read as the authority and never copied into any tracked file
  in either repository. The certification comment in the builder refers to it rather than
  restating the retired credential names, so the builder cannot re-seed them.
- No secrets are introduced. The builder holds none.

## Known issues

- **MITRE ATT&CK is absent and should probably be earned.** It is defensible on paper through
  Cisco CyberOps and Security+ objectives, but no public evidence exists in the portfolio, the
  `soc-defensive-portfolio` repository, or any local project. It was excluded rather than
  asserted. Adding a small ATT&CK-mapped artifact would make it legitimate.
- **phishtrace was evaluated and excluded, on merit rather than on presentation.** The first
  Phase 2 inspection read a stale local clone at `8211e71` and wrongly recorded "no README, no
  licence". The public repository is six commits ahead and has an 8.2 KB README with an
  architecture section, a threat model and an honest limitations section, plus `SECURITY.md` and
  an MIT licence. Corrected here during the Phase 2 closeout.
  The exclusion still stands, for a different reason: it has no tests and no CI, and its own
  README states the scores are a language model's judgement that move between runs, that there
  is no measured false-positive rate, and that it is a portfolio project rather than a
  production mail security control. Every one of the four selected projects is stronger on
  engineering rigour. Including it as a fifth would weaken the set, not broaden it.
- **Page 2 trailing whitespace was measured, reviewed and accepted as-is.** Measured by pixel
  scan of the rendered pages: page 1 fills 95.8% to 96.6%, page 2 reaches 57.7% to 63.6%. No
  layout change was made, deliberately. Page 1 is not compressed: the builder applies the same
  spacing constants throughout, so the density difference is where the content happens to break,
  not a squeeze. Every section on page 2 is complete and the document ends cleanly at Education.
  Nothing available would improve it: the two removed projects were removed on merit, phishtrace
  was excluded on merit, and certification dates purely to occupy space would be filler. A second
  page a little over half full is normal for a two-page resume and reads as finished.
- **Page 1 sits at roughly 96% full in all three maintained variants.** That is the tighter
  constraint, not the page-2 whitespace. Any future addition to the summary, skills or the first
  two roles will push a line onto page 2. Check the render, not just the diff, after such a change.
- **Removing the Hands-On Labs entry removed the only mention** of National Cyber League 2023 and
  the TryHackMe SOC Level 1 path. A deliberate trade, reversible in one line.
- The builder uses `M.Sc.`; the site uses `M.S.`. Both are canonical variants. Left alone.
